Advanced Download Manager

Take control of where your downloads go

A Chrome extension that intercepts downloads and gives you complete control over how files are downloaded — without getting in the way of normal browsing. It can route a download to Chrome's built-in downloader, a local download manager (FDM, IDM, cURL, wget), a remote download service (qBittorrent, aria2, SSH + cURL), or your clipboard as a ready-to-run cURL command.

GitHub repository  ·  Releases  ·  Privacy Policy

Features

  • 🎯 Download interception — catch downloads before they start
  • 🔗 Smart URL tracking through redirects
  • 🍪 Automatic cookie forwarding to the downloader you pick
  • 📋 Copy as cURL — a ready-to-run command with cookies included
  • 💻 Local downloader support — FDM, IDM, cURL, wget
  • 🌐 Remote downloader support — qBittorrent Web UI, aria2 RPC, SSH + cURL
  • ⚙️ Configurable options page with dark mode

Install

See the README for build-from-source and unpacked install instructions, or grab a pre-built zip from Releases.

Privacy

This extension only reads and forwards cookies to destinations you configure yourself — it never sends your data to a server run by the developer. Read the full Privacy Policy for details.
