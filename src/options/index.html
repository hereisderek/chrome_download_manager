Enable 1-Click Native Host Integration

Chromium restricts native messaging to extensions explicitly listed in the host manifest's allowed_origins. Add this extension's origin to authorize direct 1-click downloads:

Extension Origin: chrome-extension://.../

Host manifest location on macOS:
~/Library/Application Support/Google/Chrome/NativeMessagingHosts/org.freedownloadmanager.fdm5.cnh.json

Windows Registry:
HKEY_CURRENT_USER\Software\Google\Chrome\NativeMessagingHosts\org.freedownloadmanager.fdm5.cnh

Fallback Options
  • URL Protocol Scheme: If native host access is forbidden, the extension automatically invokes FDM via fdm://{url}.
  • Official FDM Extension: You can also keep the official Free Download Manager extension installed from the Chrome Web Store.

Add/Edit Remote Downloader

Create custom export command templates for tools like aria2c, axel, yt-dlp, or custom scripts. Saved templates appear in the download popup for quick one-click export.

Supported Placeholders

Placeholder Description Auto-quoting
<url> Target download link (destination URL after redirects) Auto-quoted with single quotes if not already quoted
<cookie> Cookies for the download host (supports "Compress cookies" toggle) Auto-quoted or compressed command substitution
<filename> Resolved output file name (from server headers or URL) Auto-quoted with single quotes if not already quoted
<user_agent> Browser User-Agent string Auto-quoted with single quotes if not already quoted
<host> Hostname / domain of download server Auto-quoted with single quotes if not already quoted
<browser_headers> Standard browser navigation headers (Sec-Fetch-*, Upgrade-Insecure-Requests) Expanded as individual -H '...' or --header='...' flags
<referer> Originating page URL Auto-quoted with single quotes if not already quoted

Tip: Flexible matching is supported — you can also use curly braces like {url}, <download link>, or <output file name>.

Example Command:

aria2c -x 16 -s 16 -j 16 -o <filename> --header="Cookie: <cookie>" --header="User-Agent: <user_agent>" <url>

Advanced Download Manager, v0.0.1. Intercepts downloads and routes them to the download manager of your choice, cookies included.

Features

  • Intercepts every download before it starts
  • Routes to Chrome's built-in downloader
  • Forwards to local download managers (FDM, IDM, cURL, wget)
  • Sends to remote downloaders (qBittorrent, aria2)
  • Extracts and forwards cookies and referrer automatically

Privacy

Cookies are only accessed for the URLs you download, and only sent to the downloaders you configure. Nothing goes to a third party.
